# Transformer PageView Example App

Example application demonstrating the `transformer_page_view` package for Flutter.

## Features

This example app showcases:

1. **Accordion Transformer** - Scales pages from top-right and bottom-left
2. **Scale and Fade Transformer** - Scales and fades pages as they move
3. **Depth Page Transformer** - Creates a depth effect with overlapping pages
4. **Zoom Out Transformer** - Zooms out pages during transitions
5. **3D Transformer** - Rotates pages in 3D space
6. **Loop Mode** - Demonstrates infinite scrolling
7. **Viewport Fraction** - Shows multiple pages with custom viewport
8. **Dynamic Updates** - Updates itemCount and viewportFraction dynamically

## Running the App

### Prerequisites

- Flutter SDK installed
- Android Studio or Xcode for running on simulators/devices

### Installation

1. Navigate to the example directory:
   ```bash
   cd example
   ```

2. Get dependencies:
   ```bash
   flutter pub get
   ```

3. Run the app:
   ```bash
   flutter run
   ```
